 ## 1. Aturan Desain & Revisi UI/UX (Arahan Mentor)
 ## GLOBAL DESIGN & DEVELOPMENT RULES (UPDATED AUG 2026)

**1. STRICT UI/UX DESIGN SYSTEM (BEAUTIFICATION)**
- **NO RIGID BOXES:** NEVER use sharp, rigid squares or standard boxy cards (`rounded-none` or basic `rounded`). ALWAYS use organic, asymmetric, pill-shaped, or heavily rounded containers (e.g., `rounded-3xl`, `rounded-full`) to create an artistic, flowing layout.
- **TYPOGRAPHY:** Headings and main section titles MUST use the designated script/cursive font (e.g., `font-script`) to give a premium, artistic feel. Body text remains sans-serif (e.g., Inter/SamsungOne) for readability.
- **THEME:** The overall layout must feel like a premium, international gallery. Use subtle orange gradients, generous whitespace (borderless design), and prepare areas for Batik Betawi / OPK Betawi background assets.
- **OFFICIAL LOGOS:** The Header MUST always display the 3 official logos (Jaya Raya, 5 Abad Jakarta, Dinas Kebudayaan) with balanced visual weight.

**2. CORE FEATURE REQUIREMENTS**
- **BILINGUAL SYSTEM:** The platform targets international investors. All UI elements must be built with Bilingual support (Indonesian & English) in mind.
- **DIRECT WHATSAPP:** Do not build internal chat systems. All "Contact/Booking" buttons must redirect directly to the respective Sanggar/Pemusik's WhatsApp number.
- **MEDIA SHOWCASE:** Sanggar and Pemusik details must include slots for Video Demos, not just images.s
- **PAGINATION:** Catalog lists should display a maximum of 6 items per page to ensure fast load times and a clean UI.
